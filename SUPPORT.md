# Support

plyrix is supported on a best effort basis by one maintainer, for the latest minor release only.

## Asking for help

Open an issue with the bug form for a problem, or the question form for anything else, including questions about lyrics or the LRCLIB dump. With a bug, include:

- the output of `plyrix doctor`, which names settings but never their values;
- the counts lines a normal run prints, which hold no paths or lyrics.

Don't paste `--verbose` output, as it lists the library's paths. Replace any path you do need to mention with a placeholder such as `/srv/music`, and never paste lyrics or tokens.

Security problems and conduct reports go privately through https://github.com/patrickclery/plyrix/security/advisories/new instead.
